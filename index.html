Swap WETH

What a WETH swap does

To swap WETH is to trade Wrapped Ether for another token through a liquidity route, not simply convert it back to native ETH. Ethereum's Wrapped Ether guide describes WETH as an ERC-20 representation of ether, while the ERC-20 token standard defines the approval and transfer interface that DeFi apps expect.

If your goal is only WETH to ETH on the same chain, unwrapping may be the cleaner action. If your goal is WETH to USDC, WBTC, UNI, or another ERC-20 token, a swap route is the relevant flow.

Check the WETH contract and network

On Ethereum mainnet, the WETH contract in this page's local facts is 0xC02aaA39b223FE8D0A0e5C4F27eAD9083C756Cc2 with 18 decimals. Verify that address on the Etherscan WETH token page before approving a spend, especially if a wallet shows multiple tokens with the WETH symbol.

WETH also exists on other EVM networks, but the contract and liquidity route can differ by chain. Match the wallet network to the balance you actually hold, and treat market pages only as context, not as a substitute for contract verification.

How to swap WETH on Uniswap

Open the route

Uniswap documents custom swap link parameters that can prefill an input token, so you can land closer to the WETH route before connecting a wallet.

Review the quote

The Uniswap trading overview explains that routes and quotes are part of the swap flow; check output token, recipient, minimum received, and network before signing.

Approve only what you expect

A WETH approval can be separate from the final swap. Uniswap Labs explains how approval transactions work, including wallet prompts before the swap transaction.

Fees, slippage, and price impact

Holding WETH does not normally pay Ethereum mainnet gas; you still need native ETH for transaction fees. Ethereum's gas documentation explains how computation is paid for, and Uniswap Labs lists network cost tokens by chain.

Before signing, compare the quoted output with the minimum received. Uniswap Labs defines price impact in liquidity pools and explains slippage settings in the web app, both of which matter when pool depth or market movement changes execution.

Why liquidity matters for WETH routes

WETH is common in DeFi because many contracts are built around ERC-20 transfers and approvals, but each trade still depends on available pool liquidity. Uniswap Labs describes liquidity pools and AMM pricing, while DeFiLlama's Uniswap protocol dashboard tracks protocol-level activity and can help users understand the broader liquidity landscape without inventing a quote.

Custody and security checklist

Self-custody

Uniswap swaps are wallet-signed, so the connected wallet remains the signing surface. The Uniswap Labs GitHub organization is the authoritative place to inspect public Uniswap code repositories.

Token warnings

Do not rely on a ticker alone. Uniswap Labs explains token warning labels for malicious, impersonator, honeypot, and other risk signals.

Interface and protocol costs

Review the swap details panel before signing. Uniswap Labs maintains a support page for Uniswap Labs fee disclosures, separate from gas and any protocol-level fee mechanics.

On-chain actions are irreversible once confirmed, and failed transactions can still consume network costs. This page is educational content, not financial advice.

FAQ

How do I swap WETH safely?

Open the Uniswap app from the official app domain, verify WETH and the output token, review price impact, slippage, gas, and any approval prompt, then sign only the transaction you expect. Use Etherscan's WETH contract record as a contract check.

Is swapping WETH the same as wrapping or unwrapping ETH?

No. Ethereum.org's WETH explainer describes wrapping as converting ETH into WETH and unwrapping as redeeming WETH for ETH; a swap trades WETH for another token through liquidity.

What network should I use to swap WETH?

Use the network where your WETH balance exists. On Ethereum mainnet, the WETH contract is 0xC02aaA39b223FE8D0A0e5C4F27eAD9083C756Cc2, and ethereum.org's network notes for WETH show that other chains can have different WETH contracts.

Do I need ETH to swap WETH?

Yes. On Ethereum mainnet, gas is paid in native ETH, not WETH, so keep enough ETH in the wallet for approvals and swaps. Ethereum.org documents Ethereum gas fees, and Uniswap Labs lists ETH as the network cost token for Ethereum.

Why use Uniswap to swap WETH?

Uniswap is a wallet-based DEX interface for token swaps, and Uniswap developer trading docs describe swap integration paths while still requiring users to review and sign transactions in their own wallet.
